# ModelForge
《魔兽争霸 III》模型工具链：零依赖 Python 内核（MDX/CASC/BLP/DDS 定点写入）+ 独立编辑器 ModelForge + Blender 插件。改贴图、材质、附着点、动画。Warcraft III model toolchain — a zero-dependency Python core for MDX/CASC/BLP/DDS, a standalone editor (ModelForge) and a Blender add-on. Edit textures, materials, attachments and animations.
