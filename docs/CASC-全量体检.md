## 检查了什么

每个模型都跑「解析 → 重建 → 与原始字节逐字节比对」。
重建能对上，就说明这个块里没有遗漏任何字段。

| 块 | 做法 |
|---|---|
| GEOS | 完整重建（含 LOD / TANG / SKIN / 多套 UV） |
| BONE | 逐条记录重建 + 每条动画轨道重建 |
| SEQS / TEXS / PIVT | 完整重建 |
| GEOA / MTLS | 只验证能否解析（暂无重建实现） |
